# Chrome Web Store listing copy

**Name:** KotoLens – Japanese & Korean Reader

**Summary (132 chars max):**
Highlight, right-click, learn. Japanese & Korean translations with furigana, audio, grammar notes, and built-in flashcards.

**Category:** Education
**Language:** English

**Description:**

Read the real web in Japanese and Korean without losing the thread.

Highlight any text, right-click, and pick a KotoLens option:
• Translate to Japanese 日本語: see how to say it naturally, in context
• Translate to Korean 한국어: the same for Korean
• Explain in English: understand Japanese or Korean text you run into

Each result gives you:
✓ Furigana over every kanji, with readings chosen for the context (今日 → きょう, not こんにち)
✓ Rōmaji / Revised Romanization, which you can switch off as you improve
✓ 🔊 Native text-to-speech for the phrase, the full sentence, and each word
✓ The whole sentence translated, so you see how your selection fits
✓ A vocabulary breakdown with dictionary forms and parts of speech
✓ Grammar points pulled from the actual sentence (〜ている, -(으)니까, 〜ので …)

Build your own deck as you read:
＋ Add any word or phrase to flashcards with one click. Each card keeps its furigana, meaning, and example sentence
↻ Review with spaced repetition (Again / Hard / Good / Easy)
⇄ Study Japanese/Korean → English, or English → Japanese/Korean
⇩ Export to Anki (CSV), or back up and restore as JSON

Privacy first:
• Nothing is sent until you click a KotoLens menu item
• No access to "all websites": KotoLens only sees the page you asked it to translate
• No servers, no tracking, no analytics. Flashcards stay on your device.

Powered by Claude. KotoLens uses your own Anthropic API key (get one at console.anthropic.com), so you pay Anthropic directly for what you use.

Tip: press Alt+Shift+K to explain the highlighted text without right-clicking.
